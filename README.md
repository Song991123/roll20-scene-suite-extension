# Scene Suite 확장 버전

Roll20에서 대사, 스탠딩, 오디오, 배경, APNG, 핸드아웃, 컷인, 캐릭터 이미지를 함께 다루는 Mod 스크립트 모음입니다.

각 코드는 단독으로 설치할 수 있습니다. `00_scene_director.js`를 함께 설치하면 설치된 기능을 연결하고 GM 사용법을 만듭니다.

- 제작 및 통합: [@EOOOOORK](https://x.com/EOOOOORK)
- 제작 기록: [X 타래](https://x.com/EOOOOORK/status/2089133134201995610)
- 상태: 공개 배포본

## 빠른 설치

1. `public/index.html`을 웹 서버에서 엽니다.
2. 필요한 기능을 선택합니다.
3. 방 이름과 이미지 주소처럼 필요한 값만 입력합니다.
4. `코드 복사` 또는 `파일 받기`를 누릅니다.
5. Roll20 게임의 Mod Scripts에 붙여 넣고 저장합니다.
6. 채팅에 `!도움`을 입력해 설치된 기능의 세팅법과 명령어를 확인합니다.

로컬 미리보기는 다음 명령으로 실행합니다.

```powershell
node tools/serve.js
```

브라우저에서 `http://localhost:4173`을 열면 됩니다.

## 처음 설정

> **토큰 이름 안내:** 아래에서 말하는 토큰 이름은 이미지 파일명이 아닙니다. Roll20 보드에 이미지를 끌어다 놓아 만든 이미지 토큰을 선택하고, 토큰 설정의 이름 칸에 적는 이름입니다.

### 나레이터

캐릭터 대사를 쓸 때는 `/as`와 `/emas` 이름을 캐릭터 저널 이름에 맞춥니다.

```text
!... /as "홍길동" 안녕하세요. @웃음
!... 설명입니다. @오디오 재생|문 여는 소리
```

### 오디오

Roll20 쥬크박스에 음원을 추가하고 서로 다른 제목을 붙입니다.

```text
!오디오 재생|마을 브금|반복|볼륨=30|페이드=2초
!오디오 중지|마을 브금|페이드=2초
!오디오 전체중지|페이드=3초
```

### 비주얼 노벨

1. 적용할 페이지 이름을 `page_list`에 적습니다.
2. 그 페이지의 GM 레이어에 이미지 토큰 세 개를 놓고 토큰 이름을 각각 `vd_area`, `vd_name`, `vd_dialogue`로 지정합니다.
3. 설치 페이지에서 창 구성을 고릅니다.
   - 패널 하나: 오브젝트 레이어에 이미지 토큰을 놓고 토큰 이름을 `vd_panel`로 지정합니다.
   - 창 분리: 오브젝트 레이어에 이미지 토큰 두 개를 놓고 스크립트창 토큰 이름은 `vd_panel`, 대사창 토큰 이름은 `vd_dialogue_box`로 지정합니다.
4. `standings` 덱에 `캐릭터명`, `캐릭터명-표정명` 형식으로 카드를 넣습니다.
5. 배경 전환을 쓰면 `background` 덱과 토큰 이름이 `vd_background`인 이미지 토큰을 준비합니다.

설치 후에는 `!비주얼 설정|창구성|패널 하나` 또는 `!비주얼 설정|창구성|분리`로 바꿀 수 있습니다.

외곽선은 이름, 스크립트(`/desc`, `/emas`), 대사별로 설정합니다. 이름만 켜려면 `!비주얼 설정|이름외곽선|켜기`를 사용하세요. 기존 `!비주얼 설정|외곽선|켜기` 명령은 세 영역을 모두 켭니다.

`standings` 덱과 `avatars` 덱은 따로 관리합니다. 같은 캐릭터라도 서로 다른 이미지를 쓸 수 있습니다.

스탠딩 비율은 기본 카드나 표정 카드 어느 쪽에서 등록해도 같은 캐릭터의 표정 카드에 함께 적용됩니다. 비율 등록을 삭제할 때도 같은 묶음이 삭제됩니다.

### 이미지 전환

기본값은 `image`로 시작하는 덱과 같은 이름의 이미지 토큰을 사용합니다. Roll20 보드에 놓은 토큰의 이름을 덱 이름과 같게 지정하며, 덱 카드 이름은 전환할 장면 이름입니다.

```text
!#image배경 마을회관
```

### 별도 대사창

설치 페이지에서 적용할 페이지 이름과 대사창 이미지를 입력합니다.

### APNG

1. `apng` 덱을 만들고 카드 앞면에 애니메이션을 넣습니다.
2. 전체 화면으로 재생할 때는 매크로에서 `전체`를 선택합니다.
3. 지정 영역 재생을 쓸 때만 GM 레이어에 이미지 토큰을 놓고 토큰 이름을 `apng_area`로 지정합니다.
4. `📽️apng` 매크로에서 카드, 전체 또는 영역, 1회 또는 반복을 고릅니다.

### 핸드아웃

1. 채팅에 `!핸드아웃 관리`를 입력합니다.
2. 관리할 폴더를 선택합니다.
3. 핸드아웃별 공개 대상을 선택합니다.

공개 알림 디자인은 `🖊️핸드아웃` 매크로에서 수정합니다.

### 컷인

1. `cutin` 덱을 만들고 카드 앞면에 컷인 이미지를 넣습니다.
2. `다이스-성공`, `다이스-실패`처럼 이름을 지으면 같은 앞부분을 한 크기 설정으로 묶습니다.
3. 위치를 제한할 때만 GM 레이어에 이미지 토큰을 놓고 토큰 이름을 `cutin_area`로 지정합니다.
4. 화면 전체의 어두운 배경을 쓰려면 GM 레이어에 배경 이미지 토큰을 놓고 토큰 이름을 `cutin_overlay`로 지정합니다. 이미지 파일명은 바꾸지 않아도 되며, 이미지를 저장한 토큰은 자동으로 사라집니다.
5. `!컷인 관리`에서 크기, 대사, 효과음을 연결합니다.
6. 10 시트 헬퍼를 함께 설치하면 지원되는 판정 결과와 컷인을 연결할 수 있습니다.

### 캐릭터 이미지

1. `avatars` 덱에 `캐릭터명`, `캐릭터명-표정명` 형식으로 카드를 넣습니다.
2. `!아바타 관리`에서 캐릭터 이미지와 맵 토큰 중 바꿀 대상을 정합니다. 비주얼 노벨 표정은 03에서 별도로 관리합니다.
3. 자동 변경에서 뺄 캐릭터는 제외 목록에 추가합니다.

### 시트 헬퍼

1. 채팅에 `!!관리`를 입력해 인식된 항목을 확인합니다.
2. `!!굴릴항목이름`으로 실행하고, `!!검색 이름`으로 현재 수치와 굴림 버튼을 찾습니다.

굴림, 검색, 수치 변경은 채팅창의 현재 `As` 캐릭터에 적용됩니다. `!!비밀 굴릴항목이름`은 GM에게만 결과를 보냅니다. 08 컷인을 함께 설치하면 인식 가능한 CoC 7판 판정 결과와 성공 단계를 컷인에 연결할 수 있습니다.

## 원본 스크립트와 달라진 점

### 나레이터 확장

- 기존 순차 출력, 일시정지, 취소, 줄 합치기를 유지합니다.
- 한 줄 끝에 오디오, 배경, 이미지, APNG, 핸드아웃, 컷인, 표정 명령을 함께 둘 수 있습니다.
- 줄을 출력하기 전에 연결된 명령을 먼저 검사합니다. 하나라도 잘못되면 해당 줄과 남은 줄을 취소합니다.
- `/as`, `/desc`, `/emas`와 채팅 화자 흐름을 유지합니다.
- 명령의 `|` 옵션은 가능한 항목에서 순서를 바꿔도 인식합니다.

### 비주얼 노벨 확장

- Roll20 꾸밈용 링크, 스타일, 마크다운은 채팅에 남기고 대사창에는 본문만 표시합니다.
- 일반 대사와 `/as`는 대사창, `/desc`와 `/emas`는 스크립트창에 표시합니다. 패널 하나를 고르면 모두 토큰 이름이 `vd_panel`인 이미지 토큰을 사용합니다.
- 글자가 한 글자씩 나타나는 스크립트 출력을 지원합니다.
- 스탠딩 원본 비율을 보존하고 위쪽을 기준으로 맞춥니다.
- 스탠딩 카드가 없는 캐릭터는 덱 뒷면을 대신 띄우지 않습니다.
- 표정 핸드아웃, 글꼴, 글자 크기, 색, 영역별 외곽선과 색, 스탠딩 크기, 화면 순서를 GM 버튼으로 관리합니다.
- PNG, JPG, WebM, MP4 배경 전환을 지원합니다.

### 이미지 전환 확장

- 기존 덱, 토큰, 카드 규칙과 자동 매크로 갱신을 유지합니다.
- 나레이터의 같은 줄에서 이미지 전환을 실행할 수 있습니다.
- 다른 기능의 상태를 초기화하지 않습니다.

### 새 기능

- Roll20AM 목록을 다시 등록하지 않고 쥬크박스 제목으로 직접 제어하는 오디오
- 전체 화면과 지정 영역을 고를 수 있는 APNG
- 권한과 공개 알림을 분리한 핸드아웃 관리자
- 이미지와 핸드아웃 표지를 화면 위에 표시하는 컷인 관리자
- 캐릭터 이미지와 맵 토큰을 따로 고르는 캐릭터 이미지 기능. 비주얼 노벨 표정은 독립적으로 변경
- 지원 목록에 넣은 공개 또는 커스텀 시트 원본의 굴림을 현재 캐릭터 값으로 실행하는 시트 헬퍼
- 설치된 기능만 설명하는 Scene Director 사용법

## 확인 범위

`node tools/check.js`는 다음 항목을 확인합니다.

- 00부터 10까지 파일 존재
- 모든 스크립트의 JavaScript 문법
- 공개 페이지의 파일 경로와 필수 버튼
- 배포본에 개인 이미지 주소와 GitHub 계정명이 없는지 여부
- 공개 문서에 가운데 점 문자가 없는지 여부

Roll20 실방의 실제 렌더링, 음원 스트리밍, 애니메이션 재생은 복제 캠페인에서 별도로 확인해야 합니다.

## 자동 배포

저장소는 비공개로 유지하고 `public` 폴더만 닷홈에 올리는 구성을 사용합니다.

GitHub 저장소에 다음 값을 등록합니다.

- 변수 `DEPLOY_DOTHOME`: `true`
- 비밀값 `DOTHOME_FTP_HOST`
- 비밀값 `DOTHOME_FTP_USERNAME`
- 비밀값 `DOTHOME_FTP_PASSWORD`
- 비밀값 `DOTHOME_FTP_PATH`: 예시 `html/roll20`

이후 `main` 브랜치의 `public` 폴더가 바뀌면 해당 경로만 자동 갱신됩니다. FTP 접속 정보는 페이지나 저장소 파일에 들어가지 않습니다.
