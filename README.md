# Scene Suite 확장 버전

Roll20에서 대사, 스탠딩, 오디오, 배경, APNG, 핸드아웃, 컷인, 아바타를 같은 타이밍에 다루기 위한 Mod 스크립트 모음입니다.

각 모듈은 단독으로 설치할 수 있습니다. `00_scene_director.js`를 함께 설치하면 현재 설치된 모듈만 모아서 GM 도움말과 공통 설정을 제공합니다.

- 제작 및 통합: [@EOOOOORK](https://x.com/EOOOOORK)
- 제작 기록: [X 타래](https://x.com/EOOOOORK/status/2089133134201995610)
- 상태: 공개 배포 준비본

## 빠른 설치

1. `public/index.html`을 웹 서버에서 엽니다.
2. 필요한 기능을 선택합니다.
3. 방 이름과 이미지 주소처럼 필요한 값만 입력합니다.
4. `통합 코드 복사` 또는 `통합 파일 받기`를 누릅니다.
5. Roll20 게임의 Mod Scripts에 붙여 넣고 저장합니다.

로컬 미리보기는 다음 명령으로 실행합니다.

```powershell
node tools/serve.js
```

브라우저에서 `http://localhost:4173`을 열면 됩니다.

## 처음 설정

### Narrator

별도 맵 설정은 필요하지 않습니다. `/as`와 `/emas`를 쓸 때는 캐릭터 저널 이름을 실제 발화자 이름과 맞춥니다.

```text
!... /as "홍길동" 안녕하세요. @웃음
!... 설명입니다. @오디오 재생|문 여는 소리
```

### 오디오

Roll20 쥬크박스의 오디오 관리에서 음원을 추가하고 제목을 서로 다르게 정합니다. BGM으로 분류할 제목 앞 이모지는 자동 생성되는 도움말에서 설정할 수 있습니다.

```text
!오디오 재생|마을 브금|반복|볼륨=30|페이드=2초
!오디오 중지|마을 브금|페이드=2초
!오디오 전체중지|페이드=3초
```

### Visual Dialogue

1. 설치 페이지 이름을 `page_list`에 적습니다.
2. 그 페이지의 GM 레이어에 `vd_area`, `vd_name`, `vd_dialogue` 가이드 토큰을 둡니다.
3. 오브젝트 레이어에 `vd_panel`을 둡니다. 일반 대사창 이미지를 따로 쓰면 `vd_dialogue_box`도 둡니다.
4. `standings` 덱에 `캐릭터명`, `캐릭터명-표정명` 형식으로 카드를 넣습니다.
5. 배경 전환을 쓰면 `background` 덱과 `vd_background` 토큰을 준비합니다.

스탠딩과 아바타 덱은 자동으로 합치지 않습니다. 같은 캐릭터라도 서로 다른 구도로 관리할 수 있습니다.

### Image Switcher

기본값은 `image`로 시작하는 덱과 같은 이름의 토큰을 사용합니다. 덱 카드 이름이 전환할 장면 이름입니다.

```text
!#image배경 마을회관
```

### Dialog Overlay

설치 페이지, 발화자 이름, 대사창 배경 이미지 주소를 설치 페이지에서 입력합니다. Visual Dialogue 대사를 쓰는 경우에는 중복 표시하지 않습니다.

### APNG

1. `apng` 덱을 만들고 카드 앞면에 애니메이션을 넣습니다.
2. 전체 화면 재생은 별도 영역 토큰이 없어도 됩니다.
3. 지정 영역 재생을 쓸 때만 GM 레이어에 `apng_area` 토큰을 둡니다.
4. `📽️apng` 매크로에서 카드, 전체 또는 영역, 1회 또는 반복을 고릅니다.

### 핸드아웃

`!핸드아웃 관리`로 GM 관리 핸드아웃을 만들고 관리할 폴더를 고릅니다. 보기 권한은 캐릭터를 제어하는 플레이어에게 줍니다. 기존 `🖊️핸드아웃` 매크로가 있으면 공개 알림의 꾸밈만 읽으며 매크로 내용은 바꾸지 않습니다.

### 컷인

1. `cutin` 덱에 카드를 넣습니다.
2. `다이스-성공`, `다이스-실패`처럼 이름을 지으면 같은 앞부분을 한 크기 설정으로 묶습니다.
3. 위치를 제한할 때만 GM 레이어에 `cutin_area`를 둡니다.
4. 화면 전체의 어두운 배경을 쓰려면 GM 레이어에 `cutin_overlay` 토큰을 둡니다.
5. `!컷인 관리`에서 크기, 대사, 시트 조건, 효과음을 연결합니다.

### 아바타

1. `avatars` 덱에 `캐릭터명`, `캐릭터명-표정명` 형식으로 카드를 넣습니다.
2. `!아바타 관리`에서 시트, 현재 페이지 토큰, Visual Dialogue 중 바꿀 대상을 정합니다.
3. 자동 변경에서 뺄 캐릭터는 제외 목록에 추가합니다.

## 원본 스크립트와 달라진 점

### Narrator 확장

- 기존 순차 출력, 일시정지, 취소, 줄 합치기를 유지합니다.
- 한 줄 끝에 오디오, 배경, 이미지, APNG, 핸드아웃, 컷인, 표정 명령을 함께 둘 수 있습니다.
- 줄을 출력하기 전에 연결된 명령을 먼저 검사합니다. 하나라도 잘못되면 해당 줄과 뒤쪽 큐를 취소하고 다음 입력을 받을 수 있는 상태로 돌아갑니다.
- `/as`, `/desc`, `/emas`와 Speaking As 흐름을 유지합니다.
- 명령의 `|` 옵션은 가능한 항목에서 순서를 바꿔도 인식합니다.

### Visual Dialogue 확장

- Roll20 꾸밈용 링크, 스타일, 마크다운은 채팅에 남기고 대사창에는 본문만 표시합니다.
- 일반 대사, `/as`, `/desc`, `/emas`를 구분해 대사창과 강조창에 표시합니다.
- 글자가 한 글자씩 나타나는 타자식 출력을 지원합니다.
- 스탠딩 원본 비율을 보존하고 위쪽을 기준으로 맞춥니다.
- 스탠딩 카드가 없는 캐릭터는 덱 뒷면을 대신 띄우지 않습니다.
- 표정 핸드아웃, 글꼴, 글자 크기, 색, 외곽선, 스탠딩 크기, 화면 순서를 GM 버튼으로 관리합니다.
- PNG, JPG, WebM, MP4 배경 전환을 지원합니다.

### Image Switcher 확장

- 기존 덱, 토큰, 카드 규칙과 자동 매크로 갱신을 유지합니다.
- Narrator의 같은 줄에서 이미지 전환을 실행할 수 있습니다.
- 다른 모듈의 상태를 초기화하지 않습니다.

### 새 기능

- Roll20AM 목록을 다시 등록하지 않고 쥬크박스 제목으로 직접 제어하는 오디오 모듈
- 전체 화면과 지정 영역을 고를 수 있는 APNG 모듈
- 권한과 공개 알림을 분리한 핸드아웃 관리자
- 카드, 핸드아웃, 채팅, 시트 결과와 연결하는 컷인 관리자
- 캐릭터 시트 아바타, 토큰, Visual Dialogue 표정을 선택적으로 동기화하는 아바타 모듈
- 실제 설치된 모듈만 설명하는 Scene Director 도움말

## 확인 범위

`node tools/check.js`는 다음 항목을 확인합니다.

- 00부터 09까지 파일 존재
- 모든 스크립트의 JavaScript 문법
- 공개 페이지의 파일 경로와 필수 버튼
- 배포본에 개인 이미지 주소와 GitHub 계정명이 없는지 여부
- 공개 문서에 가운데 점 문자가 없는지 여부

Roll20 실방의 실제 렌더링, 음원 스트리밍, 애니메이션 재생은 복제 캠페인에서 별도로 확인해야 합니다.

## 자동 배포

저장소는 비공개로 유지하고 `public` 폴더만 닷홈에 올리는 구성을 사용합니다.

GitHub 저장소에 다음 값을 등록합니다.

- 변수 `DEPLOY_DOTHOME`: `true`
- 비밀값 `DOTHOME_FTP_HOST`
- 비밀값 `DOTHOME_FTP_USERNAME`
- 비밀값 `DOTHOME_FTP_PASSWORD`
- 비밀값 `DOTHOME_FTP_PATH`: 예시 `html/roll20`

이후 `main` 브랜치의 `public` 폴더가 바뀌면 해당 경로만 자동 갱신됩니다. FTP 접속 정보는 페이지나 저장소 파일에 들어가지 않습니다.

## 출처와 배포 조건

`01_narrator_director.js`, `03_visual_dialogue_compatible.js`, `04_image_switcher_compatible.js`는 양천일염님의 공개 스크립트를 바탕으로 만든 확장 버전입니다. 자세한 주소는 [THIRD_PARTY_NOTICE.md](THIRD_PARTY_NOTICE.md)에 적었습니다.

원 저장소에는 확인 시점에 별도 라이선스 파일이 없었습니다. 공개 재배포 전 원 저작자에게 수정본 재배포 허락을 확인해야 합니다.
