    03

    기존 코드와 달라진 점

    원형을 유지한 부분과 Scene Suite에서 확장한 부분을 나눴습니다.

    Narrator 확장

    대사와 연출을 한 줄에서

    • 순차 출력, 일시정지, 취소, 줄 합치기 유지
    • 오디오, 배경, APNG, 핸드아웃, 컷인, 표정 동시 실행
    • 실행 전 전체 검사와 오류 시 큐 자동 취소
    • 옵션 순서를 바꿔도 읽는 한국어 명령
    Visual Dialogue 확장

    채팅 꾸밈은 남기고 본문만 표시

    • 링크, 스타일, 마크다운을 대사창에서 제거
    • 일반 대사, as, desc, emas 구분
    • 타자식 출력과 채팅 출력 시간 동기화
    • 스탠딩 비율, 표정, 글꼴, 외곽선, 화면 순서 관리
    Image Switcher 확장

    기존 규칙을 그대로 큐에 연결

    • 덱, 토큰, 카드 이름 규칙 유지
    • 카드 변경 시 매크로 자동 갱신 유지
    • Narrator 줄과 같은 타이밍에 이미지 전환
    • 다른 모듈 상태 초기화 제거
    Scene Suite 신규

    모듈은 따로, 연출은 함께

    • 쥬크박스 제목 직접 제어와 페이드
    • 전체 또는 영역 APNG와 컷인
    • 핸드아웃 권한과 공개 알림 관리
    • 시트 아바타, 토큰, 스탠딩 선택 동기화

    출처

    01, 03, 04는 양천일염님의 Roll20 공개 스크립트를 바탕으로 만든 확장 버전입니다. 원 저장소에 별도 라이선스가 확인되지 않아 공개 재배포는 허락 확인 뒤 진행합니다.
