## 문제와 검증 한계

- 원본 최대SAN 입력의 수식은 존재하지 않는 `cthulhu_mythos_inv`, `_da`, `_ow`, `_et`, `_ic` 등을 참조한다(HTML407/507). 실제 원본 최대값도 빈칸이고 브라우저에 자동계산 속성 부재 오류가 있다. 임의로99를 넣거나 원본을 수정하지 않았다. 최대SAN 정상 계산으로 통과시키지 않는다.
- 반복 기능 Add를 포인터로 누른 뒤에는 생성된 행이 없었다. 같은 버튼의 Enter 활성화로 실제 한 행을 만들었다. 이 관찰만으로 원본 CSS 또는 브라우저 자동화 중 어느 쪽 문제인지 확정하지 않는다.
- 숨은 시대/Pulp 값을 강제 변경하지 않았다. 현재 활성 한국어 시트의 버튼을 기준으로 했다.
- 광기는 관찰한4개 출력의 해당 분기만 확인했다. 숨은 선택 주사위와 모든20개 무작위 분기의 라이브 통과를 주장하지 않는다. 원본의 `SAN Roll`, `For … rounds.` 표기는 그대로 남는다.
- 별도 플레이어 계정의 권한 검증은 아직 없다. GM의 귓속말/컷인 관찰을 플레이어 검증으로 확대하지 않는다. 00–09 전체 동작을 라이브 검증했다는 뜻도 아니다.
- 람피온 확인 당시 남아 있던 반복행 인덱스 경고는 새 콘솔 및 로튼 전체 구간에서 재발하지 않았다. 원인을 확정하거나 해결됐다고 주장하지 않는다.
- 현황의 비무장 표기는 실제 `없음 / 피해 1d3+0`이다. 피해식은 검증했지만 `없음` 표기의 적절성까지 통과시키지 않는다.
