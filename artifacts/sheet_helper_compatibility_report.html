선택 방식은 각 굴림이 원본에서 직접 참조한 선택지를 센 값이다. 없는 굴림, 광기 방식, 보너스나 패널티 방식은 임의로 만들어 넣지 않는다.

표의 수치는 원본 HTML 추출 결과다. !!점검은 원본 정의, 현재 캐릭터에서 실행할 수 있는 항목, 검색용 이름을 따로 표시하므로 반복행과 현재 가시성에 따라 수가 달라질 수 있다.

이번 자동 확인

  • !!굴릴항목이름, 모호한 일부 이름은 맞는 후보만 검정 버튼으로 표시하며 선택한 항목만 한 번 실행
  • 선택값에 기본, 보너스 1/2, 패널티 1/2가 든 구조와 주사위 1개/3개 버튼이 나뉜 구조를 각각 자동 확인. 천량성 시트의 일반 및 보너스 굴림은 Roll20에서 확인
  • !!실시간, !!요약, !!일시적, !!장기적은 현재 시트의 같은 이름 원본 굴림을 우선
  • 공개 및 비밀 !!r과 101d6, 1d100001, 100자 초과, 침입식 거부
  • !!점검의 원본, 현재, 검색용 수치 분리
  • !!상태와 !!검색 이름에서 내부 변수 대신 계산된 수치 표시
  • 시트가 가진 선택 방식만 실행하며, 없는 방식을 코드가 보충하지 않음
  • 숫자 기본값을 이름으로 오인하지 않고, 굴림식이 직접 참조한 선택지는 화면 위치와 관계없이 인식
  • 번역 이름이 바뀌어도 유지되는 판정 컷인 연결과 기존 연결 설정 자동 이전
  • 같은 이름의 반복 굴림은 캐릭터와 순번으로 구분

Roll20 열에는 실제 Sheet Sandbox에서 확인한 결과만 기록했다. 천량성 시트의 사용자 추가 반복 기능치와 Bloody Mary Castle의 일반/펄프 실시간 선택을 확인했다. 마렌 헤윰 시트, 자체제작 호질, Roll20 공개 CoC 7판은 현재 로컬 검증만 완료했다. Sheet Sandbox에서 HTML/CSS를 바꾼 뒤에는 Mod API를 재시작하고 결과와 콘솔을 다시 확인한다.
