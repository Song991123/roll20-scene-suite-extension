# 한국어 시트 추가 표본 검증 기록 (2026-09-04)

## 결론

기존 대표 10종에 이어 한국어를 직접 표기하거나 한국어 번역을 실제 제공하는 시트 17종을 개발방에서 추가 확인했다. 총 한국어 시트 검증 범위는 27종이다.

계획한 후보 18종 중 `Achtung! Cthulhu CoC 7`은 `ko.json` 파일 이름과 달리 외모, 감정 등 주요 특성치와 기능명이 영어로 정의되어 있어 한국어 지원 시트 집계에서 제외했다. 이 시트만을 위한 한국어 별칭 하드코딩은 추가하지 않았다.

## 제외한 후보

`Achtung! Cthulhu CoC 7`은 실제 개발방에서 `!!상태`가 `Appearance`, `Charm`, `Appraise` 등으로 표시되었고 `!!외모`, `!!감정`을 찾지 못했다. 반면 `!!이성`은 원본 `Sanity 50` 굴림을 실행했다.

원본 `ko.json`도 `app: Appearance`, `sk-appraise: Appraise`, `sk-charm: Charm`처럼 주요 항목을 영어로 제공한다. 따라서 이는 시트 헬퍼가 한국어 번역을 놓친 회귀가 아니라, 해당 시트가 주요 굴림의 한국어 번역을 제공하지 않는 경우다.

## 자동 검사와 범위

- `node tools/check.js`는 00부터 09까지의 배포 보존 검사, 시트 계약 파서, 시트 인식, 시트 헬퍼, 컷인 연결, 핸드아웃 및 컷인 최적화 검사를 통과했다.
- 마지막 공개 문구 검사에서 10번 시트 헬퍼의 기존 문구 `가운데 점 + 질문 열기` 때문에 종료 코드 1이 발생했다. 해당 문구는 현재 09 수정 전 커밋에서 들어온 별도 10번 이슈이며 이번 범위에서 수정하지 않았다.
- 09 캐릭터 이미지 변경은 오브젝트 레이어, 연결된 캐릭터, 캐릭터명과 같은 토큰명만 대상으로 하고 `vd_standing`을 제외한다. `연결 전체` 설정은 제거된 상태다.
- 실제 Roll20 증거와 로컬 자동 검사 결과를 구분했다. 이 기록은 미실행 기능까지 보증하지 않는다.
