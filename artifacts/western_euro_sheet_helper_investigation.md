## 조사 범위

- 증상: 번역 파일이 없고 화면은 한글인 `웨스턴유로` 커스텀 시트가 시트 헬퍼에서는 영문 항목명으로 인식됨

3. 공통 파서가 그 관계를 어디서 놓치는지 파일과 줄 번호로 추적
4. 현재 배포 조건의 인식 결과와 원본 정보를 추가한 조건을 비교
5. 원인이 증명된 뒤에만 공통 수정 지점과 회귀 검사 제안

## 구현 중 확인한 추가 원인

- 원본 판정 이름 대신 이름 없는 버튼의 공통 title이 표시명으로 선택됨. 명시적 버튼 이름/본문은 보존하고, 빈 버튼은 원본 subject를 표시명으로, title은 별칭으로 유지.
- 템플릿 이름과 주사위 본문이 숨은 필드 참조에 들어 있음. 템플릿 메타데이터를 공통 파서에서 연결하고, 일반/보너스 비교에서도 기존 안전 확장 함수를 재사용해 참조된 굴림 조각을 펼침.
- 수치 참조 자체는 펼쳐 비교하지 않으므로 현재 값이 같은 다른 특성/기능을 하나로 합치지 않음.

## 확정된 사실

- Roll20 Mod API 런타임은 시트 HTML/CSS를 직접 읽지 않는다.
- 배포 전 공통 파서가 HTML/CSS/번역에서 읽어 넣은 인식 정보와, 방 안 캐릭터의 실제 저장 속성을 결합한다.
- HTML SHA-256: `30EFF7237CAA33EAB54AC98D77F175D5D92ECB4277C1F02EB7BCDB97770CB42B`
- CSS SHA-256: `AC633E6B0B5FB48A0E38ACF1B108F0F0D80EA8E7851B4C3963DC86121F86BC9A`
- HTML과 CSS를 합친 현재 생성기의 식별값은 `sheet-f3665f982d39afe2`이다.
- 원본에는 `name="roll_APP"`가 없다. 외모 굴림은 `{{subject=외모}}`와 `@{app}`, 감정 굴림은 `{{subject=감정}}`와 `@{appraise}`로 연결되어 있다.
- 공통 파서로 직접 읽은 결과는 속성 282개, 표시 항목 276개, 굴림 156개이며 `외모`, `감정`, `근력` 한글명이 정상 보존된다.
- 현재 배포용 10번에 들어 있는 인식 정보는 34종이고 `sheet-f3665f982d39afe2`는 포함되어 있지 않다.
- 웨스턴유로의 속성 282개 중 271개(96.1%)가 기존 4종과 겹친다. 원본 정보가 빠진 상태에서는 저장된 값의 조합에 따라 인식 불가가 되거나 유사한 기존 시트 쪽으로 기울 수 있다.
- 현재 34종만 두고 저장된 Attribute 이름만 재현하면 `insufficient-or-conflicting-evidence`로 인식에 실패한다.
- Roll20의 `getAttrByName`처럼 시트에 선언된 기본값까지 읽히게 재현하면 웨스턴유로를 프랑스어 공개 CoC 7판인 `sheet-f08a8b2d95ebc3cb`로 잘못 확정한다. 선택 근거는 `source-defaults`였다.
- 잘못 선택된 프랑스어 시트의 외모 굴림은 키 `app_check`, 표시명 `APP`, 별칭 `Jet de APP`이고 `외모` 별칭은 없다. 따라서 이 조건에서는 실제 문의 내용처럼 `!!APP`만 인식된다.
- 34종에 웨스턴유로 원본 정보를 추가한 재현에서는 `sheet-f3665f982d39afe2`를 선택했고, 외모와 감정이 각각 두 원본 굴림의 한글 별칭으로 잡혔으며 `APP` 별칭은 0개였다. 기존 전체 검사도 같은 실행에서 통과했다.

## 결론

- 원인은 번역 파일 부재도, 사용자가 별도 `check_list`를 적지 않은 것도 아니다.
- 웨스턴유로 원본이 배포용 지원 목록에 없고, 공통 CoC 기본값이 많이 겹치는 프랑스어 시트를 기본값만으로 확정해 버린 것이 `!!APP` 현상의 직접 원인이다.
- 수정 시에는 `APP -> 외모` 같은 런타임 하드코딩을 추가하지 않는다. 기존 생성기에 웨스턴유로 HTML/CSS를 입력하고, 생성된 정보를 기존 34종과 함께 포함하는 것이 공통 경로의 최소 수정이다.
- 적용 전 회귀 검사는 현재 34종 전체 검사와 함께 `!!외모`, `!!감정`, 일반/보너스·패널티 선택이 원본 식으로 실행되는지를 확인해야 한다.

## 이번 자료만으로 확정할 수 없는 것

- 문의자의 실제 방 데이터를 받지 않아도 제공된 원본의 기본값을 Roll20과 같은 방식으로 읽히게 하여 동일한 `APP` 선택 경로를 재현했다.
- 원본 누락, 프랑스어 시트 오인식, 원본을 추가했을 때 정확한 선택과 한글 별칭 복구까지 확인했다.
