## 이번 자동 확인

- 첫 행은 1순위 검증 대상인 `천량성 커스텀 CoC` 원본의 `coc.html`과 `coc.css`를 다시 읽은 결과다. 187 / 72 / 374를 천량성 시트의 수치로 보았던 해석만 폐기했으며, 해당 수치의 마렌 헤윰 커스텀 CoC는 별도 호환 시트로 유지한다.
- `node tools/check-sheet-contract.js`: 시트 HTML·CSS·번역 라벨·반복 행·선택 방식 추출 통과
- `node tools/check-sheet-helper.js`: 배포용 10번에 실제 시트 5종이 함께 포함됐는지 확인하고, 한 실행 코드에서 시트별 인식과 원본 굴림 실행을 검증한다.
- 천량성과 호질처럼 현재 저장 구조만으로 구분할 수 없는 경우에는 임의 선택하지 않고 GM 선택을 저장한다. 시트를 바꾼 뒤에는 `!!점검` 또는 관리 화면의 `다시 선택`으로 새 시트를 고른다.
- Bloody Mary Castle은 실제 반복 구역 근거로 구분하고, 공개 CoC 7판은 번역된 광기 이름, 자유 굴림, 원본의 주사위 1개·3개 버튼 호출을 확인한다.
- 선택값에 기본, 보너스 1/2, 패널티 1/2가 든 구조와 주사위 1개/3개 버튼이 나뉜 구조를 각각 자동 확인한다. 천량성 시트의 일반 및 보너스 굴림은 Roll20에서 확인했고, 나머지 선택 방식은 로컬 검증만 완료했다.
- 네 광기 별칭의 원본 굴림 우선, 비밀 `!!r`과 개수·면수·길이·침입식 제한을 자동 확인한다.
- `!!점검`은 원본 정의, 현재 캐릭터에서 실행할 수 있는 항목, 검색용 이름 수를 서로 다른 지표로 표시한다.
- `node tools/check-sheet-cutin.js`: 판정 결과 연결과 기존 해시 기반 컷인 설정 자동 이전 통과
- 숫자 입력칸의 `0` 같은 기본값은 굴림 이름으로 쓰지 않고, 굴림식이 직접 참조한 선택지는 화면 위치와 관계없이 읽는다.
- 선택 방식 수는 각 굴림이 원본에서 직접 참조한 선택지를 센 값이다. 코드가 시트에 없는 방식을 추가한 수가 아니다.
- 같은 굴림의 번역 이름이 바뀌어도 컷인 연결 키를 유지하고, 같은 이름의 반복 굴림은 선택지에서 구분한다.
- 시트에 없는 보너스·패널티·광기·자유 주사위는 임의로 만들지 않는다.
- `!!상태`는 PL의 현재 캐릭터에서 인식된 굴림과 계산된 수치를 보여준다.
- `!!검색 이름`은 시트가 실제로 참조한 판정값이 하나로 확인될 때만 현재 수치를 보여준다.

## 증거 구분

- **로컬 추출**: 실제 HTML/CSS/번역 파일을 파서에 넣어 나온 수치다.
- 표의 굴림·선택 방식 수는 원본 HTML 추출 수다. 반복행 입력과 현재 가시성에 따라 `!!점검`의 현재 실행 수가 다를 수 있으며, 검색용 이름 수도 별도 지표다.
- **자동 검사**: Roll20 API 동작을 재현한 로컬 하네스 결과다.
- **Roll20 실검증**: 실제 Sheet Sandbox에서 0.6.6 코드를 넣어 직접 확인한 결과만 기록한다. Sheet Sandbox의 HTML/CSS 교체 뒤에는 Mod API를 재시작하고 결과와 콘솔을 다시 확인한다.
