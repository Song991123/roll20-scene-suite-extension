## 이번 자동 확인

- `node tools/check-sheet-contract.js`: 시트 HTML·CSS·번역 라벨·반복 행·선택 방식 추출 통과
- `node tools/check-sheet-helper.js`: 임의 시트 이름 검색, 현재 수치 계산, 모호한 이름 선택 버튼, 자유 주사위식 안전 검사 통과
- `node tools/check-sheet-cutin.js`: 판정 결과 연결과 기존 해시 기반 컷인 설정 자동 이전 통과
- 숫자 입력칸의 `0` 같은 기본값은 굴림 이름으로 쓰지 않고, 굴림식이 직접 참조한 선택지는 화면 위치와 관계없이 읽는다.
- 선택 방식 수는 각 굴림이 원본에서 직접 참조한 선택지를 센 값이다. 코드가 시트에 없는 방식을 추가한 수가 아니다.
- 같은 굴림의 번역 이름이 바뀌어도 컷인 연결 키를 유지하고, 같은 이름의 반복 굴림은 선택지에서 구분한다.
- 시트에 없는 보너스·패널티·광기·자유 주사위는 임의로 만들지 않는다.
- `!!상태`는 PL의 현재 캐릭터에서 인식된 굴림과 계산된 수치를 보여준다.
- `!!검색 이름`은 시트가 실제로 참조한 판정값이 하나로 확인될 때만 현재 수치를 보여준다.

## 증거 구분

- **로컬 추출**: 실제 HTML/CSS/번역 파일을 파서에 넣어 나온 수치다.
- **자동 검사**: Roll20 API 동작을 재현한 로컬 하네스 결과다.
- **Roll20 실검증**: 실제 Sheet Sandbox에서 현재 0.6.0 코드를 넣어 확인한 경우에만 통과로 바꾼다.
