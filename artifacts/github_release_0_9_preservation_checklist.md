## 1. 비교 범위와 판정 기준

- 마지막 GitHub 배포 기준: `4d6154a5d65f0b89599e773f9a32b728bafc3359`
- 현재 비교 대상: `codex/pre-release-optimization` 작업본
- 비교 모듈: `00_scene_director.js`부터 `09_avatar_director.js`까지
- `10_sheet_helper.js`는 신규 기능이므로 배포본 동등성 비교에서 제외한다.
- 08의 기존 컷인 동작은 보존 대상이다. 08과 10의 판정 컷인 연동은 별도의 허용된 신규 기능으로 마지막 절에서 따로 검사한다.

이 문서에서 말하는 기능 보존은 바이트 단위 동일성을 뜻하지 않는다. 아래 변경은 허용한다.

1. 사용자가 요청한 버그 수정, 세부 기능, 편의 옵션
2. 외부에서 보이는 결과와 실행 순서를 바꾸지 않는 성능 개선
3. 새 모듈이 없을 때 기존 모듈의 단독 사용을 방해하지 않는 조건부 연동

아래 변경은 허용하지 않는다.

1. 요청과 무관한 기존 명령 삭제 또는 형식 변경
2. 기존 `state` 초기화, 삭제, 다른 의미로 재사용
3. 기존 덱·토큰·매크로·핸드아웃 이름 변경
4. 채팅 출력 순서, 나레이터 대기열 순서, 레이어 순서, 객체 생성·삭제 시점의 의도하지 않은 변경
5. 관련 없는 Roll20 이벤트가 새로 매크로·핸드아웃·객체 전체 갱신을 일으키는 회귀

표시 기준:

- `[x]` 현재 소스의 정적 비교 또는 자동검사로 확인
- `[ ]` 실제 Roll20 개발방에서 확인해야 완료
- `요청 변경` 사용자가 요청한 동작 변경
- `순수 최적화` 결과를 유지하면서 조회·문자열 생성·`set` 횟수만 줄인 변경
- `의도하지 않은 변경 후보` 정적 비교만으로 안전을 확정할 수 없어 실방 확인이 필요한 부분
