# 10 Sheet Helper Roll20 수동검증

이 문서는 배포 설명서가 아니다. `10_sheet_helper.js`를 실제 Roll20 방에서 확인하기 위한 수동검증표다.

검증 기준 파일

- `public/scripts/10_sheet_helper.js` 0.6.0
- 비교 대상은 `sheet_helper_compatibility_matrix.md`의 천툴루, 호질, Bloody Mary Castle, Roll20 공개 CoC 7판, inSANe, Magical Fury다.
- `dice.js`는 마지막 충돌 확인에서만 사용하고 수정하지 않는다.

로컬 문법 검사나 모의 실행은 Roll20 동작 확인으로 기록하지 않는다. 아래 항목은 전용 테스트 방에서 직접 실행한 뒤 체크한다.

## 0. 모든 시트 공통 확인

- [ ] 해당 시트 HTML과 CSS, 번역 파일로 새 `sheet_contract.js`를 만든다.
- [ ] `!!상태`에 굴릴 항목이 가나다순으로 나오며 `@{...}` 같은 내부 이름은 보이지 않는다.
- [ ] `!!검색 이름`에 이름이 비슷한 항목, 계산된 현재 수치, 검정 `굴리기` 버튼이 나온다.
- [ ] 비슷한 항목이 여러 개면 임의 실행하지 않고 검정 선택 버튼을 표시한다.
- [ ] 시트에 없는 보너스·패널티·광기·자유 주사위를 임의로 만들지 않는다.
- [ ] `!!점검`은 GM만 볼 수 있고, PL은 자기 캐릭터의 `!!상태`와 `!!검색`만 볼 수 있다.
- [ ] 시트 HTML·CSS·번역 파일을 다시 만든 뒤에도 기존 판정 컷인 연결이 유지된다.
- [ ] 같은 굴림의 번역 이름만 바꿔 새 `sheet_contract.js`로 교체해도 기존 판정 컷인 연결이 유지된다.
- [ ] 숫자 입력칸의 `0` 같은 기본값 대신 주변의 실제 굴림 이름이 표시된다.
- [ ] 굴림 버튼과 떨어져 있어도 굴림식이 직접 참조한 선택지는 실행 방식에 표시된다.
- [ ] 같은 이름의 반복 굴림이 둘 이상이면 컷인 연결 선택지에서 캐릭터와 순번으로 구분된다.

> 아래의 고정 판정·무기·주문·방어구 상세 목록은 천량성 legacy profile 전용 회귀 부록이다. 다른 시트에는 시트에서 실제로 읽힌 항목만 적용한다.

## 1. 준비

- [ ] 테스트 방의 커스텀 시트에 대상 `coc.html`과 `coc.css`를 적용한다.
- [ ] `10_sheet_helper.js`만 넣고 시트 기능이 단독으로 작동하는지 확인한다.
- [ ] `08_cutin_director.js`만 넣고 컷인 기능이 단독으로 작동하는지 확인한다.
- [ ] `08_cutin_director.js`와 `10_sheet_helper.js`만 넣은 상태에서도 판정 결과 컷인 연결이 작동하는지 확인한다.
- [ ] `00_scene_director.js`, `08_cutin_director.js`, `10_sheet_helper.js`를 함께 넣었을 때 통합 도움말과 기능 설정이 작동하는지 확인한다.
- [ ] 샌드박스에 오류 없이 `ready`가 뜨는지 확인한다.
- [ ] `시트헬퍼 검증` 캐릭터를 만들고 시트를 한 번 연다.
- [ ] 캐릭터를 나타내는 토큰 하나를 현재 페이지에 놓는다.
- [ ] GM은 화자를 `시트헬퍼 검증`으로 바꾸거나 해당 토큰 하나만 선택한다.
- [ ] 플레이어 검증용 계정에는 `시트헬퍼 검증`의 조작 권한을 준다.
- [ ] 아래 명령으로 CoC 7판 프로필을 선택한다.

```text
!시트 설정|coc7
```

- [ ] 아래 명령으로 속성을 다시 읽는다.

```text
!시트 새로고침
```

- [ ] 상태에 프로필 `CoC 7판 커스텀 시트`와 인식 개수가 표시된다.

```text
!시트 상태
```

- [ ] 관리 핸드아웃 링크가 GM에게만 온다.

```text
!시트 관리
```

- [ ] `[GM] 시트 헬퍼 관리`에 캐릭터, 판정 항목, 무기, 주문, 방어구, 시트 주사위, 수치가 표시된다.
- [ ] 도움말이 휘발성 귓말로 온다.

```text
!시트 도움말
```

- [ ] GM이 캐릭터 이름 일부만 적어 다음 명령 대상을 바꿀 수 있다.

```text
!시트 캐릭터|경태
```

- [ ] 같은 일부 이름과 맞는 캐릭터가 여러 명이면 선택하지 않고 후보를 안내한다.
- [ ] 선택을 해제하면 토큰 선택 또는 채팅 화자를 다시 사용한다.

```text
!시트 캐릭터|해제
```

- [ ] 플레이어에게 `[PL] 시트 헬퍼 사용법` 핸드아웃이 보이고 GM 명령은 들어 있지 않다.

### 쉬운 명령 확인

아래 명령은 `!시트`나 `|` 없이 같은 기능을 실행해야 한다.

```text
!!관찰력
!!비밀 관찰력
!!관찰력 보너스1
!!검증권총
!!검증주문A
!!검증방어구01
!!이성 -1d3
!!이성 +1d3
!!r 2d6+3
!!광기실시간
!!광기요약
!!검색 관찰
!!상태
!!관리
```

- [ ] 이름이 겹치면 임의 실행하지 않고 `!!판정`, `!!무기`, `!!주문`, `!!방어구` 중 맞는 형식을 안내한다.
- [ ] 없는 이름과 잘못된 수치식은 샌드박스를 멈추지 않고 휘발성 오류만 보낸다.
- [ ] `!!1d100`은 시트 헬퍼가 가로채지 않고 기존 주사위 코드가 처리한다.
- [ ] `!!일시적광기`, `!!장기적광기`는 굴림을 만들지 않고 시트 상태라고 안내한다.
- [ ] 시트에 없는 `!!운결정`, `!!명중부위`는 임의 공식을 만들지 않고 없다고 안내한다.

## 2. 판정 공통 표시

고정 판정은 모두 다음 조건을 확인한다.

- [ ] 공개 판정은 전체 채팅에 CoC 템플릿으로 표시된다.
- [ ] 캐릭터 이름과 초상화가 판정 발화자로 표시된다.
- [ ] 판정 이름, 기준값, 어려운 성공값, 극단적 성공값이 시트 값과 맞는다.
- [ ] 현재 시트에서 선택한 기본, 보너스, 페널티 주사위가 적용된다.
- [ ] 판정 한 번에 결과가 한 번만 표시된다.

### 반복행 공통 확인 순서

아래 여섯 소절에서 같은 순서로 각각 확인한다.

1. 새 행 A를 추가하고 수정치를 `0`으로 둔다.
2. 같은 행의 수정치를 소절에 적힌 변경값으로 바꾼다.
3. 사용 체크를 끄고 켜며 이름과 최종값이 손실되지 않는지 확인한다. 10번 코드는 체크 상태와 관계없이 이름이 있는 행을 판정 목록에 둔다.
4. 이름만 비우고 새로고침한다. 관리 핸드아웃에 `이름이 비어 있습니다`가 표시되고 이전 이름 명령은 실행되지 않아야 한다.
5. 이름을 복구한 뒤 같은 이름의 행 B를 추가한다. 이름 명령은 중복 오류와 두 속성 키를 표시해야 한다.
6. 행 B의 이름과 수정치를 바꾸고 A와 B의 순서를 드래그해 바꾼다. 관리 핸드아웃 순서만 바뀌고 각 명령의 값은 섞이지 않아야 한다.
7. 행 B를 삭제한다. B 명령은 찾지 못했다는 오류가 나고 A 명령은 바로 실행되어야 한다.

중복 오류에 표시된 각 속성 키는 다음 형식으로 따로 실행한다. 아래 `표시된_속성_키`만 오류 메시지의 실제 값으로 바꾼다.

```text
!시트 판정|key:표시된_속성_키
```

- [ ] 빈 이름, 같은 이름 두 행, 다른 이름으로 수정한 행이 공통 확인 순서대로 처리된다.
- [ ] 행 A와 B를 재정렬한 뒤 값이 서로 바뀌지 않는다.
- [ ] 행 B를 삭제한 뒤 A만 남는다.

## 6. 무기와 주문

### 기본 무기

기본 무기는 반복 무기와 별도 항목이다. 시트의 `weapon_name_fix`, `weapon_skill_fix`, `weapon_damage_fix`, `weapon_db_fix`, `weapon_range_fix`, `weapon_attacks_fix`, `weapon_ammo_fix`, `weapon_malf_fix`가 기본값으로 보이는지 먼저 확인한다.

- [ ] 시트의 읽기 전용 기능명은 `근접전(전투)`이고 관리 핸드아웃에는 `근접전(격투)`로 표시된다. 두 표시는 모두 `fighting_brawl` 수치를 사용한다.
- [ ] 이름 `비무장`, 피해 `1d3+피해 보너스`, 사거리 `-`, 공격 횟수 `1`, 탄약 `-`, 고장 `-`로 표시된다.
- [ ] 기본 무기는 격투 수치와 현재 피해 보너스로 판정된다.
- [ ] 반복 무기를 추가, 삭제, 재정렬해도 기본 무기는 별도 항목으로 유지된다.
- [ ] 기본 무기에는 바꿀 탄약 속성이 없으므로 탄약 변경 명령은 오류로 끝나고 다른 값은 바뀌지 않는다.

```text
!시트 무기|비무장
!시트 탄약|비무장|-1
```

### 반복 무기의 모든 입력 열

반복 무기에서 사용자가 입력하는 열은 다음 여덟 개다.

| 열 | 첫 검증값 | 바꾼 검증값 |
| --- | --- | --- |
| `weapon_name` | `검증권총` | `검증권총수정` |
| `weapon_skill` | `@{firearms_handgun}` | 아래 전체 선택지 검증 |
| `weapon_damage` | `1d6` | `2d4+1` |
| `weapon_db` | `+0` | 절반과 전체도 별도 검증 |
| `weapon_range` | `15m` | `20m` |
| `weapon_attacks` | `1` | `2` |
| `weapon_ammo` | `6` | `8` |
| `weapon_malf` | `100` | `98` |

- [ ] 새 행을 추가하고 여덟 값을 모두 넣으면 이름으로 실행된다.
- [ ] 여덟 값을 표의 변경값으로 바꾸면 관리 핸드아웃과 다음 판정에 전부 반영된다.
- [ ] 탄약을 `-2` 한 뒤 `8`에서 `6`으로 바뀌고 나머지 열은 유지된다.
- [ ] 같은 이름의 무기 두 행은 중복 오류와 두 속성 키를 표시한다.
- [ ] 이름을 비운 무기 행은 관리 핸드아웃의 경고에만 나오고 실행되지 않는다.
- [ ] 무기 행 두 개 이상을 재정렬하면 관리 핸드아웃 순서가 시트와 같고 각 행의 값은 섞이지 않는다.
- [ ] 무기 행을 수정하고 삭제한 뒤 예전 이름은 실행되지 않고 남은 행은 바로 실행된다.

```text
!시트 무기|검증권총
!시트 무기|검증권총수정
!시트 탄약|검증권총수정|-2
```

### 무기 기능 드롭다운 전체 선택지

무기 이름을 `기능선택검증`으로 두고 `weapon_skill`을 아래 순서대로 하나씩 바꾼 뒤 같은 명령을 실행한다. 결과의 일반, 어려움, 극단적 성공 기준이 연결된 시트 수치와 맞아야 한다.

```text
!시트 무기|기능선택검증
```

- [ ] 근접전 격투 `@{fighting_brawl}`
- [ ] 근접전 도검 `@{fighting_swords}`
- [ ] 근접전 도끼 `@{fighting_ax}`
- [ ] 근접전 도리깨 `@{fighting_mace}`
- [ ] 근접전 창 `@{fighting_lance}`
- [ ] 근접전 채찍 `@{fighting_whip}`
- [ ] 사격 권총 `@{firearms_handgun}`
- [ ] 사격 라이플 또는 산탄총 `@{firearms_rifle}`
- [ ] 투척 `@{throw}`
- [ ] 회피 `@{dodge}`
- [ ] 기타 전투기능 1 `@{ori_other_weapon}`
- [ ] 기타 전투기능 2 `@{repeating_other_weapon_$0_other_weapon}`
- [ ] 기타 전투기능 3 `@{repeating_other_weapon_$1_other_weapon}`
- [ ] 기타 전투기능 4 `@{repeating_other_weapon_$2_other_weapon}`
- [ ] 기타 전투기능 5 `@{repeating_other_weapon_$3_other_weapon}`

### 피해 보너스 세 선택지

전용 테스트 캐릭터의 피해 보너스를 확인하기 쉬운 값으로 두고 `weapon_damage=1d1`인 `피해보너스검증` 무기를 사용한다.

- [ ] `+0`은 피해 보너스를 더하지 않는다.
- [ ] `+round((@{damage_bonus})/2)`는 피해 보너스 절반을 반올림해 더한다.
- [ ] `+@{damage_bonus}`는 피해 보너스 전체를 더한다.
- [ ] 세 선택 모두 기능 판정과 고장 표시를 바꾸지 않는다.

```text
!시트 무기|피해보너스검증
```

### 기타 전투 `$0`부터 `$3` 재정렬

기타 전투 반복행 네 개를 위에서부터 `순서기능0=11`, `순서기능1=22`, `순서기능2=33`, `순서기능3=44`로 만든다. 무기 네 개는 기능 드롭다운에서 기타 전투기능 2부터 5를 각각 선택한다.

- [ ] 처음 순서에서 네 무기의 기준값이 각각 `11`, `22`, `33`, `44`다.
- [ ] 기타 전투 행을 `44`, `11`, `33`, `22` 순으로 재정렬하면 `$0`, `$1`, `$2`, `$3` 무기의 기준값도 각각 `44`, `11`, `33`, `22`를 따른다.
- [ ] 기타 전투 행의 이름이나 수정치를 바꾸면 해당 순번을 참조하는 무기만 바뀐다.
- [ ] 기타 전투 행 하나를 삭제한 뒤 `$3` 참조 무기는 Roll20의 없는 반복 속성 참조 오류로 끝나고 앞선 세 무기는 실행된다.
- [ ] 삭제한 행을 복구한 뒤 무기 행 자체를 재정렬해도 각 무기에 저장된 `$0`부터 `$3` 식은 유지된다.

```text
!시트 무기|순서무기0
!시트 무기|순서무기1
!시트 무기|순서무기2
!시트 무기|순서무기3
```

### 반복 주문의 모든 입력 열

반복 주문에서 사용자가 입력하는 열은 `magic_flag`, `magic_name`, `magic_time`, `magic_cost`, `magic_desc`다. 두 행을 다음처럼 만든다.

| 열 | 주문 A | 주문 B |
| --- | --- | --- |
| `magic_flag` | 체크, 값 `1` | 체크 해제, 빈값 |
| `magic_name` | `검증주문A` | `검증주문B` |
| `magic_time` | `1라운드` | 빈값 |
| `magic_cost` | `마력 1` | 빈값 |
| `magic_desc` | `주문 A 검증 문구` | 빈값 |

- [ ] 주문 A와 주문 B가 모두 이름으로 표시된다. `magic_flag`의 켜짐, 꺼짐, 빈값은 10번 코드의 주문 목록 포함 여부를 바꾸지 않는다.
- [ ] 주문 A 결과에는 시간, 비용, 설명이 전부 표시된다.
- [ ] 주문 B는 비어 있는 선택 입력칸 때문에 오류가 나지 않고 빈 내용으로 표시된다.
- [ ] 주문 B의 시간, 비용, 설명을 채우고 이름을 `검증주문B수정`으로 바꾸면 다음 실행에 반영된다.
- [ ] 두 주문의 `magic_flag`를 서로 바꿔도 이름과 내용은 유지된다.
- [ ] 같은 이름의 주문 두 행은 중복 오류와 두 속성 키를 표시한다.
- [ ] 주문 이름만 비운 행은 관리 핸드아웃의 경고에만 나오고 실행되지 않는다.
- [ ] 주문 A와 B를 재정렬하면 관리 핸드아웃 순서만 바뀌고 각 내용은 섞이지 않는다.
- [ ] 주문 B를 삭제하면 수정된 이름은 찾지 못하고 주문 A는 바로 실행된다.

```text
!시트 주문|검증주문A
!시트 주문|검증주문B
!시트 주문|검증주문B수정
```

## 8. 시트 주사위

### 자유 주사위

천툴루 시트는 `free_dice`, 공식 시트는 선택 주사위 영역을 켠 뒤 `dice_roll`에 `2d6+1`을 넣는다.

- [ ] 공개 자유 주사위가 시트 식으로 굴러간다.

```text
!!r 2d6+1
```

- [ ] 비밀 자유 주사위는 GM에게만 보인다.

```text
!!비밀r 2d6+1
```

### 광기 발작 실시간/요약

- [ ] 천툴루 시트에서는 `rand_maddess`와 `cocOther` 템플릿을 사용한다.
- [ ] 공식 시트에서는 현재 시대와 펄프/혼합 설정에 맞는 원본 광기 발작 템플릿을 사용한다.
- [ ] 실시간 명령은 실시간 결과가 나온다.

```text
!!광기실시간
```

- [ ] 요약 명령은 요약 결과가 나온다.

```text
!!광기요약
```

- [ ] 비밀 실시간/요약 광기 발작은 GM에게만 보인다.

```text
!!비밀광기실시간
!!비밀광기요약
```

### 시트에 없는 항목

- [ ] `행운 결정` 버튼이 없는 시트에서는 별도 주사위를 만들지 않는다.
- [ ] `명중부위`는 공식 시트에서 선택 주사위 영역을 켜 실제 버튼이 있을 때만 보인다.
- [ ] 천툴루 시트에서는 아래 명령이 모두 오류 안내만 보내고 샌드박스는 계속 실행된다.

```text
!!운결정
!!명중부위
```

### 공식 시트 명중부위

- [ ] 공식 시트의 선택 주사위 영역을 켠 상태에서 원본 `coc-body-hit-loc` 템플릿으로 표시된다.

```text
!!명중부위
```

- [ ] 비밀 명중부위는 GM에게만 보인다.

```text
!!비밀명중부위
```

## 9. 수치 변경

명령 전후의 실제 시트 값과 채팅 표시를 함께 확인한다. 변경 가능한 속성은 `hp`, `mp`, `san`, `luck`, `dying`, `major-wound-toggle`, `temp_insane`, `indef_insane`이다.

- [ ] 고정값 감소

```text
!시트 변경|체력|-1
```

- [ ] 주사위 증가

```text
!시트 변경|마력|+1d3
```

- [ ] 값 지정

```text
!시트 변경|이성|=50
```

- [ ] 별칭 사용

```text
!시트 변경|hp|+2
```

- [ ] 일반 채팅의 짧은 변경식도 적용된다. 이 줄은 느낌표 없이 일반 채팅으로 보낸다.

```text
:행운-1
```

- [ ] 현재값보다 큰 감소를 해도 결과가 0보다 작아지지 않는다.

```text
!시트 변경|체력|-999
```

- [ ] 추적 공개는 변화가 전체 채팅에 표시된다.

```text
!시트 추적|공개
```

- [ ] 추적 GM은 변화가 GM에게만 표시된다.

```text
!시트 추적|GM
```

- [ ] 추적 끄기는 변화 알림을 표시하지 않는다.

```text
!시트 추적|끄기
```

- [ ] GM 전용 캐릭터 추적을 끄면 플레이어 조작 권한이 없는 캐릭터의 변화 알림만 숨긴다.

```text
!시트 GM전용추적|끄기
```

- [ ] 다시 켜면 GM 전용 캐릭터의 변화 알림도 현재 추적 방식으로 표시한다.

```text
!시트 GM전용추적|켜기
```

### 체력과 이성 자동 확인

- [ ] 최대 체력 12에서 한 번에 6 이상 감소하면 `중상`이 활성화된다.
- [ ] 중상 상태에서 체력이 0이 되면 `빈사`가 활성화된다.
- [ ] 체력 알림에 변경 전후 수치, 최대치 대비 비율, 감소량이 표시된다.
- [ ] 이성이 한 번에 5 이상 감소하고 장기 광기가 해제 상태이면 지능 판정을 한 번 실행한다.
- [ ] 자동 지능 판정이 성공하면 `일시적 광기`가 활성화된다.
- [ ] 자동 지능 판정이 실패하거나 대실패하면 `일시적 광기`는 바뀌지 않는다.
- [ ] 장기 광기가 활성화된 상태에서는 같은 이성 감소에도 지능 판정을 실행하지 않는다.
- [ ] 이성 알림의 최대치는 `san_max`가 아니라 시작 이성 `san_start`를 사용한다.
- [ ] 광기표는 자동으로 굴리지 않는다.

## 13. 오류와 예외처리

오류 안내는 샌드박스를 멈추지 않고 명령을 실행한 사람에게 휘발성 귓말로 와야 한다.

### 권한

- [ ] 조작 권한이 없는 플레이어가 대상 토큰을 선택하면 `선택한 토큰을 조작할 권한이 없습니다.`가 온다.

```text
!시트 판정|관찰력
```

- [ ] 플레이어가 조작하는 캐릭터가 없으면 `사용할 캐릭터를 찾지 못했습니다.`가 온다.
- [ ] 플레이어가 조작하는 캐릭터가 둘 이상이고 화자나 토큰을 정하지 않으면 선택 안내가 온다.
- [ ] 토큰을 둘 이상 선택하면 토큰 하나만 선택하라는 안내가 온다.
- [ ] 플레이어가 GM 전용 명령을 실행하면 `GM 전용 명령입니다.`가 온다.

```text
!시트 관리
```

### 중복 이름

반복 과학에 이름이 `중복판정`인 행 두 개를 만든다.

- [ ] 같은 이름과 정확히 일치하면 항목 두 개와 내부 key를 안내한다.

```text
!시트 판정|중복판정
```

- [ ] 안내된 `key:` 값으로 실행하면 한 항목만 판정된다.

```text
!시트 판정|key:여기에_안내된_key
```

- [ ] 이름 일부만 입력해 여러 항목과 맞으면 비슷한 항목이 여러 개라는 안내가 온다.

```text
!시트 판정|중복
```

### 빈값

- [ ] 항목 이름을 비우면 빈 이름 안내가 온다.

```text
!시트 판정|
```

- [ ] 반복 과학에 값만 있고 이름이 빈 행을 만든 뒤 새로고침하면 관리 핸드아웃의 확인할 항목에 표시된다.

```text
!시트 새로고침
```

- [ ] 이름이 빈 반복 무기와 주문도 관리 핸드아웃의 확인할 항목에 표시된다.

### 잘못된 식

- [ ] `free_dice`를 `1d6+bad`로 바꾸면 자유 주사위 식 오류가 온다.

```text
!시트 자유
```

- [ ] 검증권총의 피해식을 `1d6+bad`로 바꾸면 피해식 오류가 온다.

```text
!시트 무기|검증권총
```

- [ ] 검증방어구01의 수치를 `1d6+bad`로 바꾸면 방어 수치 오류가 온다.

```text
!시트 방어구|검증방어구01
```

- [ ] 수치 변경식이 허용 형식이 아니면 형식 안내가 온다.

```text
!시트 변경|체력|1d6+1
```

- [ ] 변경할 수 없는 속성은 시트에서 직접 바꾸라는 안내가 온다.

```text
!시트 변경|근력|-1
```

- [ ] 고정 무기에는 변경 가능한 탄약 속성이 없다는 안내가 온다.

```text
!시트 탄약|비무장|-1
```

### 없는 항목과 다른 시트

- [ ] 없는 항목은 찾지 못했다는 안내가 온다.

```text
!시트 판정|없는판정항목
```

- [ ] 등록되지 않은 프로필은 프로필 오류가 온다.

```text
!시트 설정|없는프로필
```

- [ ] CoC 표식 속성이 없는 다른 시트 캐릭터를 선택하면 `CoC 7판 커스텀 시트 속성을 확인하지 못했습니다.`가 온다.

```text
!시트 판정|관찰력
```

- [ ] 오류 뒤에도 정상 캐릭터의 다음 판정이 바로 실행된다.

```text
!시트 판정|관찰력
```

## 14. 관리 핸드아웃 갱신

- [ ] 기능 이름이나 값을 바꾸고 약 1초 기다리면 관리 핸드아웃이 갱신된다.
- [ ] 반복 행을 추가하거나 삭제하면 해당 항목만 목록에 맞게 반영된다.
- [ ] 무기 탄약과 수치 변경 후 표시값이 맞다.
- [ ] 이름이 빈 반복 행은 실행 버튼 없이 확인할 항목에만 나온다.
- [ ] 관리 핸드아웃을 삭제한 뒤 `!시트 관리`를 실행하면 새로 만들어진다.
- [ ] 08 컷인이 없으면 판정 컷인 설치 안내가 표시된다.
- [ ] 08 컷인이 있으면 판정 항목, 판정 결과, cutin 덱 카드, 표시 시간을 고르는 `연결 추가` 버튼이 표시된다.

- [ ] `cutin` 덱에 결과 확인용 컷인 카드를 두고 크기를 등록한다.
- [ ] 카드의 `판정 연결`은 판정 항목을 묻지 않고 결과만 묻는다.
- [ ] `판정 연결`로 등록한 컷인은 모든 판정에서 해당 성공수준이 나오면 한 번 재생된다.
- [ ] 다음 결과를 각각 다른 카드에 연결해 어떤 기능치를 굴려도 결과와 같은 컷인이 재생되는지 확인한다.

```text
판정 실행
대성공
극단적 성공
어려운 성공
보통 성공
실패
대실패
```

- [ ] 카드의 `특정 판정 연결`에는 시트에서 읽은 모든 판정, 무기, 주문, 방어구와 아래 항목이 나온다.

```text
자유 주사위
광기 발작 실시간
광기 발작 요약
명중부위 (공식 시트에서 선택 주사위 영역을 켠 경우)
```

- [ ] `특정 판정 연결`은 선택한 항목에만 적용된다.
- [ ] 우선순위는 `특정 판정 결과`, `특정 판정 실행`, `모든 판정 결과`, `모든 판정 실행` 순서다.
- [ ] 기본, 보너스 1개, 보너스 2개, 페널티 1개, 페널티 2개에서 화면에 표시된 최종 주사위와 컷인이 일치한다.
- [ ] 기능치 49 이하에서는 96부터 대실패, 기능치 50 이상에서는 100만 대실패로 연결된다.
- [ ] `!!비밀 관찰력`은 GM에게 판정만 보이고 공개 컷인은 재생하지 않는다.
- [ ] 커스텀 시트의 판정 버튼을 직접 눌러도 한글 판정명이 같은 연결을 사용한다.
- [ ] 연결된 카드를 삭제하면 샌드박스가 멈추지 않고 GM에게 오류가 온다.
- [ ] 연결 해제 뒤에는 해당 컷인이 재생되지 않는다.

```text
!컷인 시트연결목록
```

```text
!... /desc [ 정선은 아쉬운 듯 몇 번이나 당신을 돌아보지만 @박정선:불안 @박정수:기본 ](#" style="font-size: 13px; color: #333333; text-decoration: none; font-style:normal; font-weight:normal;)
```

- [ ] 두 표정 명령이 채팅과 비주얼 노벨 본문에서 모두 제거된다.
- [ ] 박정선은 `불안`, 박정수는 `기본`으로 한 번씩 변경된다.
- [ ] 같은 줄에 오디오, APNG, 퇴장 명령이 있어도 왼쪽에서 오른쪽 순서로 한 번씩 실행된다.

## 17. dice.js 충돌 확인

`dice.js`는 수정하지 않는다. `10_sheet_helper.js`와 명령 영역이 직접 겹치지 않는지만 확인한다.

- [ ] `dice.js`만 추가하고 샌드박스에 전역 이름 재선언 오류가 없는지 확인한다.
- [ ] `!시트` 명령 한 번에 시트 결과가 한 번만 나온다.

```text
!시트 판정|관찰력
```

- [ ] 일반 주사위는 `dice.js` 결과만 한 번 나온다.

```text
1d6
```

- [ ] 선택은 `dice.js` 결과만 한 번 나온다.

```text
choice[빨강,파랑]
```

- [ ] `hp+3`, `이성-1`은 일반 채팅으로만 표시되고 시트 값은 바뀌지 않는다.
- [ ] `:`를 붙인 수치 변경은 시트 값만 한 번 바뀌고 `dice.js` 결과가 추가되지 않는다.

```text
:hp+3
:이성-1
```

- [ ] `choice.js`와 사용자가 붙여 준 두 번째 범용 주사위 예시는 함께 설치하지 않는다. 함께 설치하면 `choice`, 일반 주사위, 비밀 주사위 결과가 중복될 수 있다.
