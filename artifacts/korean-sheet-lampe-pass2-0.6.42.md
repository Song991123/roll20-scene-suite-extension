# 람피온의 저택: 한국어 실검증 2차 (0.6.42)

개발 Sheet Sandbox 14742251만 사용했다. 원본 HTML/CSS/번역.txt는 수정하지 않았다. 설치된 10번 전체 원문은 로컬 0.6.42와 일치했다(LF 665,441자). 제품 코드, 00–09, 공개 배포본은 이번 검증에서 변경하지 않았다. 탄약 추가 작업은 계속 보류한다.

## 실제 환경과 진단

- 최초 `legacy:false` 환경에서는 HTML의 `skill-input`과 CSS의 `.sheet-skill-input` 등이 맞지 않았다. 인류학 값은 1인데 버튼 중심을 다른 표의 독순술 셀이 가려, 포인터 클릭이 굴림을 실행하지 못했다.
- 개발방 Sheet.json을 `legacy:true`로 맞추고 실제 재접속 및 Mod 재시작(Ready 8.53초)을 했다. 클래스 접두어와 레이아웃이 정상화된 화면을 확인했다. 이전 11쌍은 진단 자료로 분리하고, 정상 렌더링에서 51항목 전체를 다시 대조했다.
- 이는 검증 환경 설정 변경이다. 원본 시트나 Sheet Helper에 시트별 예외 코드를 넣지 않았다.

## 한계·아직 통과로 보지 않는 항목

- 같은 탭 재접속이 경고창 이후 로딩에 멈췄으나, 새 개발 탭의 정상 접속으로 로그·굴림 보존을 확인했다. 멈춘 탭3은 닫았다. 새 탭 생성 후 이전 탭을 가리키던 전송 콜백도 다시 연결했다. 이전 빈 목록/무응답을 제품의 로그 소실이나 굴림 실패로 판정하지 않았다.
- Mod 콘솔에서 `ERROR: You tried to use the repeating section row at index 0...3 for repeating_skills, but there doesn't seem to be a row at that index.` 경고를 확인했다. 이후 사용하지 않는 자체 검사 스크립트 `zz_codex_sheet_qa.js`를 비활성화하고 새 콘솔(Ready 8.70s)에서 상태, 다시 읽기, 감정을 실행했을 때는 재발하지 않았다. 이 검사 스크립트는 명시적 QA 명령에만 반응하며 속성을 조회하지 않으므로 비활성화가 경고를 고쳤다고 판단하지 않는다. 기존 `bar_traker.js`는 보존했다. 경고의 발생 경로는 미해결이다.
- 별도 플레이어 계정의 권한 검증은 이 기록에 포함하지 않는다. GM 화면의 귓속말/컷인 관찰을 플레이어 검증으로 확대하지 않는다.
- 숨겨진 시대/Pulp 값은 강제로 쓰지 않았다. 활성 1920 계열의 실제 버튼만 사용했다. 광기 숨은 선택 d10과 모든 무작위 분기를 실제로 굴렸다고 주장하지 않는다.
- SAN 원본 캡션 `SAN Roll`, 실시간 지속시간의 `For … rounds.`는 원본 출력에도 있다. 한국어 명령 `!!이성`·`!!실시간`의 실행 실패와 구분한다.
- 기준0/주사위1에서 원본 템플릿의 독립 조건에 따라 대성공과 실패가 함께 출력되는 사례가 있었다. 원본과의 일치는 확인했지만 템플릿 자체를 수정하지 않았다.
- 반복행의 삭제 버튼 중심을 원본 굴림 버튼이 가린다. 포인터 클릭은 굴림을 실행했고, 키보드 활성화 후 실제 행0을 확인했다. 삭제 응답만 보고 성공 처리하지 않았다.
- 테스트 도구의 빈 문자열 입력이 일부 값을 실제로 비우지 못했다. Ctrl+A/Backspace/Tab으로 지우고 전체 입력을 다시 읽어 복원을 확인했다.
- 자원 검증기의 최초2.5초 관찰은 HP UI 반영 전에 끝났다. 같은 감소의 나중 UI(HP3/13·중상ON)를 확인하고 이어서 검증했다. 감소를 재실행하지 않았다.
- 현황에는 특성8, 기능44(기존 변경기능63 포함), 비무장1, 광기2, 자원3이 표시된다. 비무장 표기는 `없음 / 피해 1d3+0`까지 실제 그대로 기록했다.
