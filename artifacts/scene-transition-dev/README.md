# APNG 장면전환 실험용

사이트 배포 전 로컬 테스트용입니다. 독립 가사 코드와 마기로기는 포함하지 않습니다.

## 설치와 등록

1. 기존에 설치한 동일 모듈을 비활성화하고 테스트 합본 하나만 사용합니다. 개별 교체도 가능합니다.
2. 기존 `apng` 덱에 앞 연출과 뒤 연출 카드를 넣습니다.
3. SceneDirector 사용법의 `APNG 관리` 버튼 또는 `!APNG 관리`를 누른 뒤 `관리 핸드아웃 열기`로 이동합니다. 저널에서 `[GM] APNG 관리`를 직접 열어도 됩니다.
4. `장면전환 만들기`에서 이름, 앞뒤 APNG, 각 시간, 전체 또는 영역을 지정합니다.
5. 기본 중간 명령은 비워도 됩니다. 필요한 모듈이 설치된 경우에만 명령을 넣습니다.

## 일반 APNG 재생

관리 핸드아웃은 다른 관리 화면과 같이 검정 제목과 섹션, 회색 안내 상자, 용도별 색상의 버튼을 사용합니다. `적용 설정`, `APNG 재생`, `장면전환`을 나누어 표시합니다.

카드마다 다음 버튼을 사용할 수 있습니다.

- `전체` / `지정 영역`: 카드의 재생 위치를 먼저 선택합니다. 선택한 위치에 체크가 표시되며 다음 실행에도 유지됩니다.
- `실행`: 체크된 위치에 등록한 재생 시간 동안 표시한 뒤 화면에서 제거합니다.
- `반복 실행`: 중지할 때까지 표시합니다. 연결된 음원이 있으면 기존 음원 연동 설정을 따릅니다.
- `중지`: 해당 카드가 아직 표시 중이면 즉시 제거합니다. 다른 카드나 등록 정보는 지우지 않습니다.
- `재생 시간 변경`: 일반 실행의 표시 시간만 바꿉니다. 선택한 위치, 장면전환에 따로 등록한 앞뒤 시간과 기존 기본 재생 방식은 유지합니다.
- `음원 연결` / `음원 변경` / `연결 해제`: 카드에 연결할 주크박스 음원을 설정합니다. 현재 연결된 음원 이름을 함께 표시합니다. 기존처럼 한 음원은 한 APNG에 연결되며, 다른 카드에 다시 연결하면 이전 연결은 해제됩니다.

음원 연결과 장면전환 등록은 06의 관리 핸드아웃에서 처리합니다. 00에는 관리 진입 버튼과 명령어 안내만 남깁니다. 06 단독으로도 등록할 수 있으며, 연결 음원을 함께 재생할 때만 기존처럼 02 오디오가 필요합니다.

일반 재생은 장면전환 등록 없이 사용할 수 있습니다. 반면 장면전환은 앞뒤 APNG를 각각 1회 사용합니다. 카드의 재생 시간과 전환 프리셋의 시간은 서로 독립적입니다.

영역은 기존 `apng_area` 토큰을 사용합니다. 전체는 기존 APNG의 페이지 또는 맵시트 크기를 사용합니다. 불투명 배경이나 검정 덮개는 자동으로 만들지 않습니다. 투명하거나 부분적으로만 나타나는 연출도 사용할 수 있습니다.

## 사용

```text
!APNG 전환|슬라이드
!APNG 전환|슬라이드|@비주얼 배경 외부인숙소_2층복도 @오디오 중지|숙소 계단
!APNG 전환|슬라이드|@이미지 image_room|ON
!APNG 전환|슬라이드|-
!APNG 전환중지
```

앞 연출 시간이 지난 뒤 중간 명령을 실행하고, 뒤 연출을 재생합니다. `|-`는 저장한 중간 명령을 이번 실행에서만 생략합니다. 비주얼 배경을 반드시 바꾸지 않습니다. 다른 모듈이 없으면 앞뒤 APNG 효과만 사용합니다.

여러 전환은 들어온 순서대로 처리합니다. 전환 중지는 전환용 토큰과 대기열만 정리합니다. `!APNG 중지`는 기존 전체 APNG 중지와 함께 장면전환도 취소합니다. 등록 정보는 유지합니다.

## 나레이터와 사용

```text
!... @장면전환 슬라이드
```

저장한 기본 중간 명령을 실행하며, 전체 전환 시간보다 짧게 다음 줄을 시작하지 않습니다. 일반 줄 간격이 더 길면 그 간격은 유지합니다.

이 실행에서만 중간 명령을 지정하려면 기존 묶음 형식을 사용할 수 있습니다.

```text
!... {{@장면전환|슬라이드|@비주얼 배경 외부인숙소_2층복도 @오디오 중지|숙소 계단}}
```

`!... @장면전환 슬라이드 @비주얼 배경 ...`처럼 일반 줄 끝 명령으로 분리하면 비주얼 명령은 기존처럼 즉시 실행됩니다. 중간 시점에 실행할 명령은 저장한 기본 명령, `!APNG 전환`의 인자, 또는 위 묶음 안에 넣으세요.

`!/`는 나레이터가 시작한 전환도 취소합니다. 독립 실행 중인 전환은 취소하지 않습니다. 중간 명령 실패 시 남은 나레이터 줄도 취소합니다.

## 검사와 한계

- 생성한 버튼의 실제 href를 추출하고 질의 응답을 대입한 뒤 채팅 명령 처리기로 전달해 저장, 수정, 실행, 삭제를 검사했습니다.
- 06 단독, 01+06, 00+01+06 조합을 검사했습니다. 실제 02 오디오와 04 이미지 어댑터도 중간 시점에만 실행되는지 검사했습니다.
- 전체와 영역, 대기열, 취소, 권한, 대상 삭제, 기존 APNG 재생을 모의 검사했습니다.
- 1.2.2-dev 후속 검증에서는 21992313 방에서 실제 버튼 클릭, 입력창, 저장과 갱신, 토큰 생성 위치와 중지를 확인했습니다. 작업자가 WebM 프레임이 움직이는 모습을 직접 확인하지는 못했으며, 이후 사용자가 방에서 "잘되는듯?"이라고 동작을 확인했습니다. 모의 검사, 작업자의 직접 관찰과 사용자 확인을 구분합니다.
- 1.2.3-dev에서는 같은 방에 00과 06만 교체하고 APNG 관리 진입, 음원 선택창, 연결, 변경, 해제와 표시 갱신을 실제 버튼으로 확인했습니다. 테스트 연결은 해제했고 기존 연결은 보존했습니다. 모의 검사 30개 묶음과 빠른 회귀 검사도 통과했습니다. 이번에는 음원이나 애니메이션 재생을 다시 시험하지 않았습니다.
- 이미 실행한 배경 변경이나 오디오 명령은 되돌리지 않습니다. 모든 명령을 미리 검증하지만, 실행 도중 실패한 외부 연출의 롤백을 보장하지는 않습니다.
- APNG는 영상의 실제 끝을 읽지 않고 등록한 시간을 사용합니다. 앞 연출 시간은 원하는 중간 실행 시점에 맞춰 등록하세요.
