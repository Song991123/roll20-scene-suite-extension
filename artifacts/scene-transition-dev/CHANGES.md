# 설명 변경과 모듈 분리 점검

## 설명 감사

| 코드 | 기존 확인 사항 | 보완 내용 |
| --- | --- | --- |
| 00 | `!.`, `@다음줄` 설명은 이미 존재 | 나레이터 설정, 시간 단위와 범위, 공통 줄 간격, 귓말, 전환 대기 추가. 각 모듈의 실제 설정 또는 도움말 진입 명령 추가 |
| 01 | 동시 출력과 다음 줄 대기 존재 | 독립 도움말에 랜덤 선택과 귓말 추가. `!.` 뒤 내용 필요, 시간 단위 설명 보완 |
| 02 | 재생, 중지, 볼륨, 페이드와 설정 화면 존재 | 자체 설명 유지. 00에 `!오디오 설정` 진입 설명 추가 |
| 03 | 기본 표정, 콜론을 비운 지정 표정, `!.`, `@다음줄`, 줄 간격 설명 존재 | 자체 코드 유지. 공통 줄 간격 설명을 00 나레이터 항목에도 배치 |
| 04 | 토큰 이름, 파일명 구분, 기존 `img_` 지원 설명 존재 | 자체 설명 유지. 00에 설정 진입과 `img_` 호환 설명 추가 |
| 05 | `!dialog-status`, `!dialog-page` 명령 존재 | 자체 코드 유지. 00에 실제 상태 확인과 페이지 등록 명령 추가 |
| 06 | 카드 재생, 영역, 효과음 연결 설명 존재 | 독립 관리 핸드아웃, 전환 만들기, 앞뒤 시간, 전체/영역, 중간 명령, 효과만 실행, 취소, 나레이터 대기 설명 추가 |
| 07 | 공개 매크로 최소 양식과 권한 설명 존재 | 자체 코드 유지. 00에 설정 진입 설명 추가 |
| 08 | 그룹, 영역 토큰, 배경 토큰, 판정 연결 설명 존재 | 자체 코드 유지. 00에 설정 진입 설명 추가 |
| 09 | 지정 캐릭터 표정 변경 설명 존재 | 자체 도움말과 어댑터 도움말에 기본 표정, 콜론 비우기 추가. 00과 설치 설명에도 반영 |
| 10 | 자체 도움말에 기능치 알림 설정 존재 | 자체 코드 유지. 누락됐던 00과 설치 설명에 기능치 알림 설정 추가 |

설치 페이지의 01, 06, 09, 10 설명을 함께 보완했습니다. 추가 설명은 가운데 점 없이 핵심 명령과 동작만 적었습니다. 존재하지 않는 `!대사창 설정`, `!아바타 설정` 같은 명령은 문서에 넣지 않았습니다.

## 동작 변경과 결합도

| 소유 모듈 | 변경 | 독립성 |
| --- | --- | --- |
| 06 | 전환 프리셋, 핸드아웃, 타이머 1개, 순차 대기열 | 효과만 사용하면 00, 01, 03, 04 불필요 |
| 공통 어댑터 | 기존 `aliases`, `validate`, `cue` 경로 사용 | 설치된 모듈만 선택 호출. 새 중앙 실행기나 역방향 import 없음 |
| 01 | 일반 어댑터의 `waitMs` 수용, 비동기 오류와 취소 통지 | APNG 전용 상태나 함수명 참조 없음. 06이 없으면 기존 동작 |
| 04 | 직접 명령과 어댑터가 같은 명령 처리 함수 사용 | 06 참조 없음. 채팅 재전송에 따른 지연 제거. 기존 토큰, 덱, URL 처리 재사용 |
| 00 | 명령어 안내와 APNG 관리 진입 버튼 | 전환 관리 HTML이나 음원 목록을 직접 만들거나 가져오지 않음 |

기존 APNG 재생 설정, 효과음 연결, 카드 ID, 기존 나레이터, 표정과 배경 설정을 초기화하지 않습니다. 새 상태는 `state.KIBSceneAPNG.transitions`, 프리셋 번호, 관리 핸드아웃 ID만 추가합니다. 독립 가사 파일은 수정하거나 합본에 포함하지 않습니다.

## 검사

- `node tools/check-apng-transitions.js`: 22개 검사 묶음 통과
- `node tools/check.js --fast`: 문법, 배포본 보존, 기존 빠른 회귀 검사 통과
- `node tools/check-handout-cutin-optimization.js`: 기존 최적화 검사 통과
- 실제 Roll20 버튼 클릭과 화면 재생은 미검증

기존 27종 시트 실방 검증을 다시 했다는 뜻은 아닙니다. 이번 변경에서는 시트 헬퍼를 수정하지 않았습니다.

## APNG 관리 화면 후속 개선 (1.2.1-dev)

- 07 핸드아웃과 08 컷인 관리의 제목 크기, 검정 섹션 제목, 테두리, 회색 안내 상자, 버튼 색상을 재사용했습니다. 공통 코드나 다른 모듈을 참조하는 의존성은 추가하지 않았습니다.
- 페이지, 카드 덱, 전체 재생, 지정 영역 안내를 `적용 설정`으로 분리했습니다.
- `APNG 재생`은 카드별 `실행`, `반복 실행`, `중지`, `재생 시간 변경`을 제공합니다. 카드 이름 대신 ID를 사용하므로 이름의 기호가 명령 구분자로 섞이지 않습니다.
- 불명확한 `1회, 한 사이클 2초` 대신 `재생 시간: 2초`로 표시합니다. 시간 변경은 재생 방식이나 장면전환 시간을 바꾸지 않습니다.
- `장면전환`에는 앞 APNG, 뒤 APNG, 각 시간과 실제 중간 명령을 보여줍니다. 버튼은 `전환 실행`, `전환 설정 수정`처럼 일반 재생과 구별했습니다.
- 장면전환의 진행 순서, 중간 명령 생략, 전체/영역, 나레이터 연동, 취소 범위를 완전한 문장으로 설명했습니다.
- 새 버튼의 실행과 중지, 시간 변경, 설정 보존 및 스타일 계층을 검사했습니다. 로컬 HTML 렌더링도 확인했지만 Roll20 안에서의 클릭과 재생 검증은 별도입니다.

## 실제 핸드아웃 버튼 수정 (1.2.2-dev)

- 실제 방에서 카드 버튼 40개에 href가 사라진 것을 확인했습니다. 질의문보다 앞에 있던 id: 대신 버튼은 id=로 생성하며, 기존 id: 명령도 계속 지원합니다.
- 카드마다 전체와 지정 영역 선택 버튼, 현재 재생 위치를 추가했습니다. 체크한 위치로 실행하며 시간 변경 때 위치를 초기화하지 않습니다.
- 수정 범위는 06과 생성 소스 목록, 해당 검사와 이 설명입니다. 다른 모듈의 실행 코드는 변경하지 않았습니다.
- 모의 검사 25개 묶음과 빠른 회귀 검사 통과. 사용자 허가를 받은 21992313 방에서 버튼 입력, 저장, 갱신, 생성 토큰의 위치와 크기, 중지 및 전환 관리 명령을 확인했습니다.
- WebM 애니메이션의 프레임 재생은 확인하지 못했습니다. 버튼이 명령을 전송하고 토큰을 생성한 결과와 분리합니다. 사이트 배포는 하지 않았습니다.
- 최종 코드 저장 후 사용자가 방에서 "잘되는듯?"이라고 확인했습니다. 임시 진단 코드와 검증용 프리셋은 남기지 않았습니다.

## APNG 관리 역할 분리 (1.2.3-dev)

- 00 사용법의 장면전환 생성 화면과 APNG 음원 연결 화면을 제거했습니다. 상단과 06 설명에는 APNG 관리 진입 버튼을 두고 명령어 안내는 유지합니다.
- `!APNG 관리`와 인자 없는 `!APNG 설정`은 기존 07과 08처럼 관리 핸드아웃을 여는 링크만 안내합니다.
- 06 관리 핸드아웃에서 카드별 연결 음원 이름과 음원 연결, 변경, 해제 버튼을 제공합니다. 기존 음원 연결, 카드 설정, 전환 프리셋과 핸드아웃 ID는 유지합니다.
- 생성 버튼은 `id=`를 사용하며 기존 `id:`와 제목 입력도 지원합니다. 음원 추가, 이름 변경, 삭제 때 목록을 갱신하고 재생 상태나 볼륨 변경만으로 관리 화면을 갱신하지 않습니다.
- 00이 06의 관리 HTML을 호출하던 어댑터 항목을 제거했습니다. 재생, 검증과 선택적 음원 연동 어댑터는 그대로입니다. 새 모듈 의존성은 없습니다.
- 모의 검사 30개 묶음과 빠른 회귀 검사를 통과했습니다. 이번 실방 확인 내용은 WORKLOG의 후속 항목에 별도로 기록합니다. 사이트 배포는 하지 않습니다.

## 같은 줄 자동 큐 (1.2.4-dev)

- 나레이터에서 장면전환 뒤의 직접 입력한 @명령을 중간 시점에 자동 실행합니다. 앞 명령은 즉시 실행하며, 다음 장면전환부터는 별도 전환 묶음으로 대기열에 들어갑니다.
- 01은 선택적 어댑터의 collectFollowing 선언에 따라 뒤 명령을 전달할 뿐 APNG 상태나 내부 함수를 참조하지 않습니다. 06이 기존 전환 대기열과 중간 실행을 소유합니다. 00 없이 01과 06만 설치한 경우도 지원합니다.
- 저장된 중간 명령과 기존 묶음 문법을 유지합니다. 자동 글자 출력과 대사 자동 컷인은 기존 줄 시점에 실행합니다. 꺼진 모듈은 기존처럼 생략합니다.
- 00이 없는 경우에도 실행 전 어댑터 검증을 거칩니다. 뒤 명령이 잘못되면 앞 명령을 실행하기 전에 해당 나레이터 줄을 취소합니다. 중간 시점에 다시 검증하고 실패하면 남은 줄을 취소합니다.
- 00 명령어 안내와 06 관리 설명에 일반 한 줄 표기의 실행 시점을 추가했습니다. 로컬 검사만 수행했으며 사이트 배포와 실방 적용은 하지 않았습니다.
