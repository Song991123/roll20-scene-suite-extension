## 같은 줄 자동 큐 (1.2.4-dev)

브랜치: dev/apng-inline-queue. 수정 전 b498b53은 dev/backup-apng-manager-b498b53으로 보존.

- 기존 동작은 같은 줄의 연출을 즉시 실행하고 전환의 waitMs는 다음 나레이터 줄에만 적용했다. 별도 묶음 문법을 요구하지 않도록 같은 줄 뒤 명령을 전환의 중간 실행에 자동 연결했다.
- 01은 collectFollowing을 선언한 어댑터에 followingCues 문맥을 전달한다. APNG 전용 상태나 내부 함수는 참조하지 않으며 새로운 타이머, 실행기나 폴링은 만들지 않았다.
- 06은 기존 전환 계획에 후속 명령을 추가하고 실행 전과 중간 시점에 검증한다. 기본 중간 명령은 보존하며 그 뒤에 후속 명령을 실행한다.
- 같은 줄의 여러 전환은 다음 전환 명령부터 별도 대기열 항목으로 분리한다. 기존 묶음 문법은 외부 명령을 수집하지 않으며 자동 글자 출력과 대사 자동 컷인의 시점도 유지한다.
- 사용자가 제시한 다방 롤꾸와 명령을 검사에 포함했다. 전체중지는 즉시, 퇴장과 음원 재생과 배경은 1200ms에 실행되고 뒤 APNG가 이어진다. 00 없는 조합도 확인했다.
- 실행 전 전체 취소, 중간 오류와 나레이터 취소, 연속 전환, 기존 저장 명령, 꺼진 기능, 표정의 아바타 대체 경로, 일반 줄 동작을 포함해 모의 검사 39개 묶음과 빠른 회귀 검사를 수행했다.
- 이번 버전은 로컬 테스트 합본만 제공한다. 실방은 아직 이전 1.2.3-dev이며 사이트 배포, 원격 푸시, 브라우저 조작이나 API 재시작은 하지 않았다. 이전 PNG는 이 버전의 실행 증거로 제공하지 않는다.
