## 실제 방에서 발견된 버튼 결함 (1.2.2-dev)

브랜치: dev/apng-manager-buttons. 1ed09bb는 dev/backup-apng-manager-ui-1ed09bb로 보존.

- 실제 관리 핸드아웃에서 카드 버튼 40개의 href가 제거된 것을 확인했다. 장면전환 만들기 링크는 남아 있으며 실제 입력창도 열렸다.
- 버튼용 카드 및 프리셋 ID는 id=로 생성한다. 기존 id: 직접 명령은 그대로 지원한다.
- 카드별 전체와 지정 영역 선택을 재생 버튼 앞에 배치하고 현재 위치를 표시한다. 시간 변경 시 위치를 유지한다.
- 로컬 모의 검사 25개 묶음과 빠른 회귀 검사 통과.
- 사용자 허가를 받아 망종 세팅용[API 업글2] 방(21992313)의 06만 교체했다. 다른 모듈의 내용은 교체 전후 문자열 일치로 보존 확인했다.
- 실제 시간 변경 입력창, 저장 후 핸드아웃 갱신, 전체/지정 영역 선택과 체크 갱신 확인.
- 버튼 전송 명령과 실제 생성 토큰을 임시 콘솔 진단으로 대조했다. 전체는 1600x1200 / objects, 영역은 apng_area와 같은 847.826x575.284 / map으로 생성됐다. 중지는 activeIds가 비는 것을 확인했다.
