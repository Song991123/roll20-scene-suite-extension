# 세션 시계 1.0.1

Roll20 지도에 게임 속 시간이나 실제 카운트다운을 표시하는 독립 Mod 스크립트입니다. Scene Suite와 함께 쓰거나 이 코드만 사용할 수 있습니다. 다른 스크립트의 설정, 토큰, 핸드아웃은 변경하지 않습니다.

## 처음 사용하기

1. `session-clock.js` 전체를 새 Mod 스크립트에 붙여넣고 저장합니다. 기존 버전이 있다면 교체하고 중복 설치하지 마세요.
2. 시계를 보여줄 페이지의 **GM 레이어**에 이미지 토큰 하나를 놓고, 표시할 위치와 크기로 조절합니다. 토큰 회전은 0도여야 합니다.
3. 그 토큰을 선택하고 `!시계 영역등록`을 입력합니다.
4. `!시계 시간|06:00`으로 시간을 정하고 `!시계 ON`을 입력합니다.
5. 이후 `!시계 설정`에서 버튼으로 조작합니다. 영역 등록 버튼을 쓸 때도 토큰을 선택해야 합니다.

검정 배경과 흰 Rubik Mono One 글자가 등록한 영역에 표시됩니다. 영역용 토큰 자체는 그대로 두며, 등록 시점의 위치와 크기를 저장합니다. 토큰을 옮겼다면 다시 등록하세요. 영역은 가로 80px, 세로 20px 이상이어야 합니다.

**GM만 조작할 수 있습니다.** 플레이어는 해당 페이지의 지도에서 시계를 봅니다. 브라우저 화면에 고정되는 패널이 아니라 지도 위 표시이므로 페이지 이동, 지도 확대와 축소를 따라갑니다.

## 시계

게임 속 시간을 수동으로 조작합니다. 자동으로 시간이 흐르지 않습니다.

| 명령 | 동작 |
| --- | --- |
| `!시계 설정` | 설정 버튼과 현재 상태 |
| `!시계 시간\|06:30` | 현재 시간 설정 |
| `!시계 간격\|30분` | 증가와 감소 버튼의 기본 간격 설정 |
| `!시계 증가` | 설정한 간격만큼 증가 |
| `!시계 감소` | 설정한 간격만큼 감소 |
| `!시계 증가 15분` | 이번에만 15분 증가 |
| `!시계 감소 1시간30분` | 이번에만 1시간 30분 감소 |
| `!시계 알림\|끄기` | 공개 시간 변동 알림 끄기 |
| `!시계 알림\|켜기` | 공개 시간 변동 알림 켜기 |
| `!시계 모드\|시계` | 타이머를 멈추고 시계 표시로 전환 |

시간은 24시 기준으로 입력합니다. `6` 또는 `06:00`도 가능합니다. 표시는 자동으로 `AM 06:00`, `PM 06:00`처럼 바뀝니다. 정오는 `PM 12:00`, 자정과 `24:00`은 `AM 12:00`입니다. 자정을 넘는 증감은 다음 또는 이전 날의 시각으로 순환합니다. 날짜는 표시하지 않습니다.

증감 시간은 `1시간`, `30분`, `1시간30분`, `01:30`처럼 지정합니다. 단위 없는 정수는 분으로 취급합니다. 시계 증감에는 초를 사용하지 않습니다.
주석의 `(n분)`은 선택 인수를 뜻하며 실제 입력에는 괄호를 붙이지 않습니다. 별도 수치를 넣어도 디폴트 증감 간격은 바뀌지 않습니다.

ON 상태에서 시간을 바꾸면 기본적으로 전체 채팅에 이전 시간과 변경 시간을 알립니다. OFF이거나 알림을 끄면 GM에게만 알려줍니다. 안내 메시지는 채팅 기록에 저장하지 않습니다.

## 타이머

| 명령 | 동작 |
| --- | --- |
| `!타이머 설정 00:10:00` | 시작 시간을 10분으로 설정하고 타이머 모드로 전환 |
| `!타이머 시작` | 남은 시간부터 시작 또는 재개하며 표시도 ON |
| `!타이머 일시정지` | 남은 시간을 유지하고 정지 |
| `!타이머 초기화` | 정지하고 설정한 시작 시간으로 되돌리기 |

시작 시간은 `10분`, `1시간30분`, `3초`, `00:10:00`으로 지정할 수 있습니다. 범위는 1초부터 99:59:59입니다. `10:00`은 10시간이므로 10분은 `10분` 또는 `00:10:00`으로 입력하세요.

설정만 해서는 시작하지 않습니다. 시작하면 `00:10:00` 형식으로 초까지 표시하며 약 1초마다 갱신합니다. 종료 시 `00:00:00`을 남기고 전체 채팅에 한 번 알린 뒤 예약 작업을 종료합니다. 다시 시작하면 설정한 시작 시간부터 실행합니다. 타이머 작동 중 `시간` 명령으로 게임 시간을 설정하면 카운트다운을 멈추고 시계로 전환합니다.

## ON과 OFF

| 명령 | 동작 |
| --- | --- |
| `!시계 ON` | 시계 표시 켜기. 실행 중인 카운트다운은 정지 |
| `!타이머 ON` | 타이머 표시 켜기. 정지된 카운트다운은 자동으로 시작하지 않음 |
| `!시계 OFF` 또는 `!타이머 OFF` | 표시 제거, 실행 중인 타이머와 크기 보정 예약 취소, 남은 시간 초기화 |

시계와 타이머는 같은 등록 영역을 번갈아 사용합니다. `!타이머 ON`은 표시만 바꾸며, 이미 실행 중인 카운트다운을 처음부터 다시 시작하지 않습니다.

OFF해도 등록 영역, 게임 속 시간, 증감 간격, 타이머 시작 시간, 알림 설정은 보존합니다. 다시 `!타이머 시작`하면 보존한 시작 시간부터 카운트다운합니다. OFF 직후에는 남은 시간이 0이므로 시작 시간부터 표시하려면 `!타이머 초기화` 또는 `!타이머 시작`을 입력하세요. Mod/API가 재시작되어도 표시와 실행은 OFF로 시작하며 자동 재개하지 않습니다.

기존 매크로 호환을 위해 `!시계 타이머|00:10:00`, `!시계 시작`, `!시계 일시정지`, `!시계 초기화`와 `!시계 증가|15분` 형식도 사용할 수 있습니다. 설정 버튼은 새 `!타이머` 명령을 사용합니다.

등록 페이지나 이 스크립트가 만든 표시가 삭제되면 남은 표시와 예약 작업도 정리합니다. 다른 이미지 토큰이나 텍스트는 삭제하지 않습니다. 표시 제거에 실패하면 GM에게 알리고 예약 작업은 중지합니다. Mod 콘솔에서 원인을 확인하고 `!시계 OFF`를 다시 입력하세요.

## 지원 범위와 검사

- 최신 Roll20 VTT의 `pathv2` 객체를 사용합니다. 구형 Classic VTT는 이 버전의 지원 대상이 아닙니다.
- 영역 안에 한 줄로 맞추며 가로와 세로의 비율에 따라 여백이 남습니다. 글자를 찌그러뜨려 영역 전체를 덮지는 않습니다.
- 글자 크기는 먼저 계산하고 Roll20이 제공하는 텍스트 경계값으로 최대 3회 보정합니다. 클라이언트가 경계값을 늦게 제공하면 최초 계산값을 사용합니다. 실제 방에서 표시를 확인하고 필요하면 영역 크기를 조절한 뒤 재등록하세요.
- 정지된 시계는 주기 작업을 실행하지 않습니다. 타이머는 하나의 갱신 예약만 사용합니다. 샌드박스가 일시 지연되면 실제 종료 시각을 기준으로 남은 시간을 다시 계산합니다.
- 다른 시나리오에서도 사용할 수 있게 조사 장소, 이동 규칙, Google Sheets 자동 읽기는 넣지 않았습니다.

로컬 검사:

```text
node --check standalone/session-clock/session-clock.js
node standalone/session-clock/test.cjs
```

26개 자동 검사는 권한, 새 명령어와 기존 명령어 호환, 파싱, 시간 계산, 표시 객체 생성, 제한된 크기 보정, 일시정지와 재개, OFF 정리, 재시작, 오류와 삭제 처리를 모의 환경에서 확인합니다. 실제 Roll20 방에서 코드 설치, 버튼 클릭, 배경과 글자 렌더링까지 통과했다는 뜻은 아닙니다. Rubik Mono One이 실제 Roll20 글꼴 선택 목록에 있는 것만 별도로 확인했습니다.
